# 약속 - 가족 복약 알림 (푸시 알림 버전)

폰이 꺼져있거나 앱을 안 보고 있어도, 정해진 시간에 진짜 폰 알림(소리 포함)이 오는 복약 알림 서비스예요.

## 1. 구조

- `server.js` : 매분 시간을 확인하고, 복약 시간이 되면 등록된 기기에 푸시 알림을 보내는 서버
- `public/` : 가족 등록, 약 등록, 체크리스트가 있는 웹페이지
- `data.json` : 가족/약/체크 기록이 저장되는 파일

## 2. 배포하기 (Render.com 기준, 무료로 시작 가능)

### 2-1. GitHub에 코드 올리기
1. [github.com](https://github.com) 에서 새 저장소(repository)를 만들어요. (Public이든 Private이든 상관없어요)
2. 이 폴더 전체를 그 저장소에 업로드해요. (GitHub 웹사이트에서 "Add file → Upload files"로 폴더 안 파일들을 끌어다 놓으면 돼요. `node_modules` 폴더는 올리지 않아도 돼요.)

### 2-2. Render에서 배포
1. [render.com](https://render.com) 에 가입하고 로그인해요. (GitHub 계정으로 바로 가입 가능)
2. 대시보드에서 **New + → Web Service** 선택
3. 방금 만든 GitHub 저장소를 연결해요.
4. 설정값:
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: 처음엔 Free로 시작해도 되고, 아래 "중요" 참고
5. **Create Web Service** 누르면 몇 분 뒤 `https://your-app-name.onrender.com` 같은 주소가 생겨요. 이 주소가 앞으로 가족들이 쓸 링크예요.

환경 변수(VAPID 키)는 기본값이 코드에 들어있어서 안 건드려도 바로 작동해요. 나중에 보안을 더 신경 쓰고 싶으면 `server.js` 상단 주석을 참고해서 Render의 **Environment** 탭에 직접 값을 넣어주면 돼요.

### ⚠️ 중요: 무료 요금제의 "잠자기" 문제
Render 무료 요금제는 **15분 동안 아무 방문자가 없으면 서버가 잠들어요.** 서버가 자고 있으면 매분 시간을 체크하는 기능도 멈춰서, 복약 시간에 알림이 안 갈 수 있어요.

해결 방법 두 가지 중 하나를 꼭 해주세요:
- **(쉬운 방법, 무료)** [UptimeRobot](https://uptimerobot.com) 같은 무료 서비스에 가입해서, 배포된 주소로 5분마다 한 번씩 자동으로 방문(ping)하도록 설정해요. 이러면 서버가 계속 깨어있어요.
- **(더 확실한 방법, 유료)** Render에서 유료 플랜(월 7달러 정도, Starter)으로 바꾸면 항상 켜져 있어요. 복약 알림처럼 놓치면 안 되는 용도라면 이쪽을 추천해요.

## 3. 가족들이 사용하는 방법

1. 배포된 링크(`https://your-app-name.onrender.com`)를 부모님 폰(안드로이드 크롬)으로 열어요.
2. 가족 구성원을 추가하고, 약 이름·시간·요일을 등록해요.
3. 화면 위 **"알림 켜기"** 버튼을 누르고, 알림 권한을 허용해요. (이 버튼은 각 기기에서 한 번씩 눌러야 해요 — 예를 들어 부모님 폰, 자녀 폰 둘 다에서 알림 받고 싶으면 각자 폰에서 한 번씩 눌러야 해요.)
4. 크롬 메뉴(⋮) → **"홈 화면에 추가"** 를 누르면 앱 아이콘처럼 홈 화면에 생겨요.
5. 이후로는 앱을 안 열어놔도, 등록한 시간이 되면 폰 알림이 소리와 함께 와요. 눌러서 앱을 열고 체크하면 돼요.

## 4. 알아두면 좋은 점

- 데이터는 서버의 `data.json` 파일에 저장돼요. Render 무료 요금제에서 **코드를 다시 배포하면 이 파일이 초기화될 수 있어요.** 오래 쓰실 거면 나중에 실제 데이터베이스(예: Render의 무료 PostgreSQL)로 옮기는 걸 도와드릴 수 있어요.
- 아이폰은 iOS 16.4 이상이어야 하고, 크롬이 아닌 **Safari로 열어서 "홈 화면에 추가"** 한 뒤에만 알림이 작동해요. (사파리 앱 안에서만 열어둔 상태로는 푸시 알림이 안 와요.)
- 안 될 때 체크리스트: ① 링크를 크롬(또는 아이폰은 사파리)으로 열었는지 ② "알림 켜기"를 누르고 허용했는지 ③ 홈 화면에 추가했는지 ④ Render 서버가 잠들어 있지 않은지(UptimeRobot 설정 확인)
